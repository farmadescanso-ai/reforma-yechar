# Backups Reforma Yéchar

Guarda aquí los archivos JSON exportados desde el panel para tener copias de seguridad.

**Cómo usar:**
1. En el panel, pestaña "Guardar / Restaurar" → **Exportar datos**
2. Guarda el archivo en esta carpeta (o en tu ubicación preferida)
3. Si pierdes datos, usa **Importar datos** y selecciona el último backup

**Formato del archivo:** JSON con `obra`, `presupuestos` (con partidas y estado `terminada`) y `pagos`.
